Blockdaemon is an institutional blockchain infrastructure company founded in 2017 by Konstantin Richter. It runs production node infrastructure, staking, indexed data, DeFi, custody, and tokenization services across 80+ blockchain protocols for 400+ institutional clients including Goldman Sachs, Microsoft, JP Morgan, and Citi Ventures. The Blockdaemon API Suite bundles a unified Data API (Ubiquity), JSON-RPC nodes, a Staking API, Staking Reporting API, DeFi aggregator (expand.network), Token Pricing API, Chain Watch event streaming, and a Management API. Wallet products include Builder Vault TSM (MPC for builders), Institutional Vault (self-hosted MPC custody with Automated Approver Service), and Wallet Transact. Earn Stack covers a no-code embeddable Earn Widget plus liquid staking and restaking. Compute Unit metering, triple-mode authentication, an MCP server, and SOC 2 Type II / ISO 27001 certifications round out the platform. $110B+ in digital assets secured and $10B+ staked on Blockdaemon validators.

**Areas:** Blockchain · Web3 · Staking · Validator · Custody · MPC · Wallets · Node · RPC · DeFi · Indexer · Tokenization

## How this profile is made
